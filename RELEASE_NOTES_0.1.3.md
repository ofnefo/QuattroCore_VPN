# Quattro 0.1.3 — кандидат на выпуск

Версия 0.1.2 на GitHub остаётся рабочим опубликованным релизом. Изменения ниже
готовятся в ветке `codex/0.1.3-dns-regression`; установка поверх рабочего клиента
не выполняется автоматически.

## Исправление запуска DNS

При активном внешнем Tailscale предыдущая локальная сборка добавляла DNS-сервер
с `detour: direct`. Quattro создаёт direct-выход без дополнительных параметров,
и ядро отклоняет такой DNS-транспорт на запуске:

```
start dns/udp[dns-external-tailscale]: detour to an empty direct outbound makes no sense
```

Лишний detour удалён. DNS-транспорт подключается напрямую без промежуточного
выхода. Добавлен регрессионный тест на реальном ядре: ошибочная конфигурация
воспроизводит отказ, исправленная успешно запускается. Отдельный локальный
DNS-тест проверяет разрешение имени `*.ts.net` до FakeIP.

## Остальные изменения относительно GitHub 0.1.2

- Прямые правила для банков, платежей, Госуслуг, Windows Update и локальных сетей.
- Прямые DNS-правила до FakeIP; отдельная обработка локальных суффиксов.
- Восстановление подключения с очисткой DNS-кэша Windows.
- Последовательная обработка подписок и сохранение старых серверов при пустом
  или некорректном ответе; корректный статус неудачного обновления в интерфейсе.
- Ежедневное уведомление о новой версии, отключаемое в настройках.

## Версия и упаковка

Приложение имеет версию `0.1.3.0`, обновлятор — `QuattroUpdate-0.1.3.exe`.
Упаковка отклоняет приложение с несовпадающей версией до изменения каталога
подготовки архива. Ошибочный локальный обновлятор под номером 0.1.2 отозван.

Проверка старой сборки только компиляцией и CRC архива была недостаточной.
Регрессионные тесты DNS не заменяют проверку полного TUN, системного прокси,
локальной сети и Tailscale на целевом компьютере. Этот кандидат пока не считается
проверенным опубликованным релизом.
