# Quattro 0.1.2

Исправляющий выпуск для отображения подписки и прямой маршрутизации.

## Что изменилось

- Ручной выбор содержит полный список подписки без переименования или удаления
  серверов. Блок `Авто | Самый быстрый` показывается первым: сначала алмазный
  сервер, затем остальные Auto-профили; далее сохраняется исходный порядок.
- Minimax и AnyDesk удалены из стандартных прямых исключений. Старые правила,
  созданные Quattro для этих сервисов, удаляются после обновления.
- Стандартный список прямых исключений теперь содержит российские сервисы:
  Яндекс/Яндекс Диск, VK/Mail.ru, Ozon/Wildberries и 2ГИС.
- Steam остаётся отдельным переключателем.
- Удалена подпись «Умная маршрутизация для Windows».

## Windows

- `Quattro-v0.1.2-windows-universal-installer.exe` — установка на x64, ARM64 и
  legacy x86/x64.
- `Quattro-v0.1.2-windows-update.exe` — обновление существующей x64-установки с
  сохранением подписки и настроек.
